Plural Rules

How to make nouns and adjectives plural — ties to gender and numbers.

Main rules
If the word ends in… Add Singular → Plural Pronunciation (plural)
vowel (a, e, i, o, u) -s casa KAH-sah → casas KAH-sahs KAH-sahs
libro LEE-broh → libros LEE-brohs LEE-brohs
café kah-FEH → cafés kah-FEHS kah-FEHS
consonant -es papel → papeles pah-PEH-lehs
mujer moo-HEHR → mujeres moo-HEH-rehs moo-HEH-rehs
doctor → doctores dohk-TOH-rehs
-z change z → c + -es lápiz LAH-pees → lápices LAH-pee-sehs LAH-pee-sehs (LatAm) / LAH-pee-thehs (Spain)
pez → peces PEH-sehs / PEH-thehs
stressed vowel + n/s (some) -es examen ehk-SAH-mehn → exámenes eh-KSAH-meh-nehs ehk-SAH-meh-nehs
inglés een-GLEH-sehs / een-GLEH-thehs → ingleses een-GLEH-sehs / een-GLEH-thehs

Plural tips
  • Vowel → add -s; consonant → add -es.
  • -z → -ces.
  • Stress marks may shift: examen ehk-SAH-mehn → exámenes eh-KSAH-meh-nehs.
  • Mixed-gender groups often use masculine plural: los niños lohs NEE-nyohs, los amigos lohs ah-MEE-gohs.
