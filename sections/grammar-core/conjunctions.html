Conjunctions

Connecting words and phrases — and, or, but, because, if, when

Coordinating conjunctions

Coordinating conjunctions join equals: two words, two phrases, or two independent clauses.

pero vs sino

Both can mean but. Sino SEE-noh replaces a negated idea (“not X, but Y instead”).

Use Prefer Example Pronunciation English
Contrast / add information pero PEH-roh Quiero ir, pero estoy cansado. KYEH-roh eer PEH-roh ehs-TOY kahn-SAH-doh 🔊 KYEH-roh eer PEH-roh ehs-TOY kahn-SAH-doh I want to go, but I'm tired.
After a negative: not A, but B sino SEE-noh No es médico sino profesor. noh ehs MEH-dee-koh SEE-noh proh-feh-SOHR 🔊 noh ehs MEH-dee-koh SEE-noh proh-feh-SOHR He's not a doctor but a teacher.
After a negative + a full clause sino que SEE-noh keh No estudia, sino que trabaja. noh ehs-TOO-dyah SEE-noh keh trah-BAH-hah 🔊 noh ehs-TOO-dyah SEE-noh kay trah-BAH-hah He doesn't study; rather, he works.
Not only… but also… no solo… sino también noh SOH-loh SEE-noh tahm-BYEHN No solo canta sino también baila. noh SOH-loh KAHN-tah SEE-noh tahm-BYEHN BEYE-lah 🔊 noh SOH-loh KAHN-tah SEE-noh tahm-BYEHN BEYE-lah Not only does she sing, she also dances.

Quick test: if you can say “on the other hand / however,” use pero PEH-roh. If you are correcting a negated word, use sino SEE-noh.

Subordinating conjunctions

These introduce a dependent clause (the idea cannot stand alone).

Spanish Pronunciation English Example
que keh kay that Creo que es verdad. KREH-oh keh ehs behr-DAHD 🔊
porque POHR-keh pohr-KAY because Estudio porque quiero aprender. ehs-TOO-dyoh POHR-keh KYEH-roh ah-prehn-DEHR 🔊
cuando KWAHN-doh KWAHN-doh when Te llamo cuando llego. teh YAH-moh KWAHN-doh YEH-goh 🔊
mientras MYEHN-trahs MYEHN-trahs while / as long as Leo mientras como. LEH-oh MYEHN-trahs KOH-moh 🔊
aunque OWN-keh OWN-kay although / even if Salgo aunque llueve. SAHL-goh OWN-keh YWEH-beh 🔊
si see see if Si llueve, me quedo. see YWEH-beh meh KEH-doh 🔊
para que PAH-rah keh PAH-rah kay so that (purpose) Hablo despacio para que me entiendas. AH-bloh dehs-PAH-syoh PAH-rah keh meh ehn-TYEHN-dahs 🔊

Notes on mood

  • porque POHR-keh + indicative (a real reason): Lo hago porque quiero. loh AH-goh POHR-keh KYEH-roh 🔊
  • para que PAH-rah keh + subjunctive (purpose, different subject): Te lo explico para que lo entiendas. teh loh ehks-PLEE-koh PAH-rah keh loh ehn-TYEHN-dahs 🔊
  • Same subject → use para PAH-rah + infinitive, not para que PAH-rah keh: Estudio para aprender. ehs-TOO-dyoh PAH-rah ah-prehn-DEHR 🔊
  • cuando KWAHN-doh + indicative (habit / past / now); + subjunctive (future not yet happened): Cuando llegue, te llamo. KWAHN-doh YEH-heh teh YAH-moh 🔊
  • si see (if) has no accent. sí see = yes.

Conjunction tips
  • y ee → e eh before i- / hi- (not hie-): Francia e Italia FRAHN-syah eh ee-TAH-lyah. 🔊
  • o oh → u oo before o- / ho-: siete u ocho SYEH-teh oo OH-choh. 🔊
  • pero PEH-roh = but (however). sino SEE-noh = but rather (after no noh).
  • ni nee… ni nee… = neither… nor…: ni tú ni yo nee too nee yoh. 🔊
  • porque POHR-keh (because, one word, no accent on que) vs por qué por keh (why?).
  • para que PAH-rah keh needs a new subject + subjunctive; same subject → para PAH-rah + infinitive.
  • si see = if; sí see = yes.
