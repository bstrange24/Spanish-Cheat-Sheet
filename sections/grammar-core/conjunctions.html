Conjunctions

Connecting words and phrases — and, or, but, because, if, when

Coordinating conjunctions

Coordinating conjunctions join equals: two words, two phrases, or two independent clauses.

pero vs sino

Both can mean but. Sino replaces a negated idea ("not X, but Y instead").

Use Prefer Example Pronunciation English
Contrast / add information pero Quiero ir, pero estoy cansado. KYEH-roh eer PEH-roh ehs-TOY kahn-SAH-doh I want to go, but I'm tired.
After a negative: not A, but B sino No es médico sino profesor. noh ehs MEH-dee-koh SEE-noh proh-feh-SOHR He's not a doctor but a teacher.
After a negative + a full clause sino que No estudia, sino que trabaja. noh ehs-TOO-dyah SEE-noh kay trah-BAH-hah He doesn't study; rather, he works.
Not only… but also… no solo… sino también No solo canta sino también baila. noh SOH-loh KAHN-tah SEE-noh tahm-BYEHN BEYE-lah Not only does she sing, she also dances.

Quick test: if you can say "on the other hand / however," use pero. If you are correcting a negated word, use sino.

Subordinating conjunctions

These introduce a dependent clause (the idea cannot stand alone).

Spanish Pronunciation English Example Pronunciation
que kay that Creo que es verdad. KREH-oh keh ehs behr-DAHD
porque pohr-KAY because Estudio porque quiero aprender. ehs-TOO-dyoh POHR-keh KYEH-roh ah-prehn-DEHR
cuando KWAHN-doh when Te llamo cuando llego. teh YAH-moh KWAHN-doh YEH-goh
mientras MYEHN-trahs while / as long as Leo mientras como. LEH-oh MYEHN-trahs KOH-moh
aunque OWN-kay although / even if Salgo aunque llueve. SAHL-goh OWN-keh YWEH-beh
si see if Si llueve, me quedo. see YWEH-beh meh KEH-doh
para que PAH-rah kay so that (purpose) Hablo despacio para que me entiendas. AH-bloh dehs-PAH-syoh PAH-rah keh meh ehn-TYEHN-dahs

Notes on mood

  • porque + indicative (a real reason): Lo hago porque quiero. loh AH-goh POHR-keh KYEH-roh
  • para que + subjunctive (purpose, different subject): Te lo explico para que lo entiendas. teh loh ehks-PLEE-koh PAH-rah keh loh ehn-TYEHN-dahs
  • Same subject → use para + infinitive, not para que: Estudio para aprender. ehs-TOO-dyoh PAH-rah ah-prehn-DEHR
  • cuando + indicative (habit / past / now); + subjunctive (future not yet happened): Cuando llegue, te llamo. KWAHN-doh YEH-heh teh YAH-moh
  • si (if) has no accent. sí = yes.

Conjunction tips
  • y → e before i- / hi- (not hie-): Francia e Italia FRAHN-syah eh ee-TAH-lyah.
  • o → u before o- / ho-: siete u ocho SYEH-teh oo OH-choh.
  • pero = but (however). sino = but rather (after no).
  • ni… ni… = neither… nor…: ni tú ni yo nee too nee yoh.
  • porque (because, one word, no accent on que) vs por qué (why?).
  • para que needs a new subject + subjunctive; same subject → para + infinitive.
  • si = if; sí = yes.
