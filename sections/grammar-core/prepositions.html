Contractions (must memorize)

Form = Pronunciation Example
al a + el ahl Voy al banco boy ahl BAHN-koh.
del de + el dehl Cerca del parque SEHR-kah dehl PAHR-keh.

No contraction with la: a la, de la.

Por vs para (the important contrast)

Rough guide

  • Para → destination, purpose, deadline, recipient, opinion
  • Por → reason, exchange, duration, movement through, "per," passive "by"
Use Prefer Example Pronunciation English
Recipient (for someone) para Esto es para ti. EHS-toh ehs PAH-rah tee This is for you.
Purpose (in order to) para Estudio para aprender. ehs-TOO-dyoh PAH-rah ah-prehn-DEHR I study in order to learn.

Destination para Salgo para Madrid. SAHL-goh PAH-rah mah-DREED I'm leaving for Madrid.

Preposition tips
  • Voy a España boy ah ehs-PAH-nyah (to) vs Estoy en España ehs-TOY ehn ehs-PAH-nyah (in).
  • Soy de México soy deh MEH-hee-koh = I'm from Mexico.
  • Always: al = a + el, del = de + el.
  • If you mean "in order to + verb," use para + infinitive.
  • If you mean "because of / thanks for / through," lean por.
