Negation

Saying no, never, nothing, nobody — and double negatives

no before the verb

Put no immediately before the conjugated verb.

Spanish Pronunciation English
No hablo francés. 🔊 noh AH-bloh frahn-SEHS (LatAm) / frahn-THEHS (Spain) I don't speak French.
No estoy cansado. 🔊 noh ehs-TOY kahn-SAH-doh I'm not tired.
No he comido. 🔊 noh eh koh-MEE-doh I haven't eaten.
No quiero ir. 🔊 noh KYEH-roh eer I don't want to go.
No, gracias. 🔊 noh GRAH-syahs (LatAm) / GRAH-thyahs (Spain) No, thank you.

Object pronouns stay attached to the verb group: No lo veo. 🔊 — I don't see it.
No me gusta. 🔊 — I don't like it.

Double negation

Spanish requires a second negative after the verb. No veo nada is correct — not “I don't see nothing” as an error.

Spanish Pronunciation English
No veo nada. 🔊 noh BEH-oh NAH-dah I don't see anything.
No conozco a nadie. 🔊 noh koh-NOHS-koh ah NAH-dyeh (LatAm) / koh-NOHTH-koh (Spain) I don't know anybody.
No voy nunca. 🔊 noh boy NOON-kah I never go.
No tengo ningún problema. 🔊 noh TEHN-goh neen-GOON proh-BLEH-mah I don't have any problem.
No me gusta tampoco. 🔊 noh meh GOOS-tah tahm-POH-koh I don't like it either.

You can stack them: No le digo nunca nada a nadie. 🔊 — I never tell anybody anything.

Placement

If the negative word is before the verb, drop extra no.
If it is after the verb, keep no.

Negative first (no extra no) Verb first (need no) English
Nunca voy. 🔊 No voy nunca. 🔊 I never go.
Nadie vino. 🔊 No vino nadie. 🔊 Nobody came.
Nada pasó. 🔊 No pasó nada. 🔊 Nothing happened.
Ninguno funciona. 🔊 No funciona ninguno. 🔊 None of them work.
Tampoco quiero café. 🔊 No quiero café tampoco. 🔊 I don't want coffee either.

Ya no and todavía no keep no next to the verb: Ya no trabajo. 🔊 / Todavía no termino. 🔊

ningún / ninguno / ninguna
Form When Example English
ningún before a masculine singular noun ningún libro no book / not any book
ninguno pronoun (stands alone, m.) No quiero ninguno. 🔊 I don't want any (of them).
ninguna feminine singular (noun or pronoun) ninguna casa no house
ningunos / ningunas rare; usually stay singular No tengo ninguno. 🔊 I don't have any.

Positive “some / someone / something”: alguien, algo, algún / alguno. Don't mix them with no in the same way: not no veo algo → No veo nada. 🔊

Negation tips
  • Default: no right before the verb: No sé. 🔊
  • After the verb, Spanish loves a second negative: No veo nada. 🔊
  • Negative word first → no extra no: Nunca voy. 🔊
  • Nadie as a direct object still needs personal a: No veo a nadie. 🔊
  • ningún before masc. noun; ninguno alone.
  • ya no = no longer; todavía no = not yet; tampoco = neither.
  • English “I don't see anything” = Spanish “I don't see nothing.” That's the rule, not a mistake.
