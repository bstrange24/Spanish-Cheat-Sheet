Imperfect Subjunctive

The imperfect subjunctive is used for past wishes, doubts, hypothetical situations, and polite requests, or after past-tense triggers of the subjunctive.
There are two interchangeable sets of endings (-ra and -se). The -ra forms are more common in modern Spanish.
Every form includes pronunciation. Default = LatAm; Spain only if different.

Quick start
Idea Spanish term Example Pronunciation English
Dictionary form infinitive hablar ah-BLAHR to speak
Base for conjugation 3rd-person plural preterite hablaron → drop -ron ah-BLAH-rohn
Ending that shows imperfect subjunctive conjugation hablara / hablase ah-BLAH-rah / ah-BLAH-seh that I spoke / I would speak

How to form it

Take the ellos/ellas form of the preterite, drop the -ron, and add the endings below.

Imperfect Subjunctive endings (regular) – -ra forms (most common)

Person -ar -er / -ir Pronunciation pattern
yo -ara -iera -ara = AH-rah; -iera = YEH-rah
tú -aras -ieras -aras = AH-rahs; -ieras = YEH-rahs
él / ella / usted -ara -iera same as yo
nosotros / nosotras -áramos -iéramos AH-rah-mohs / YEH-rah-mohs
vosotros / vosotras (Spain) -arais -ierais AH-rah-ees / YEH-rah-ees
ellos / ellas / ustedes -aran -ieran AH-rahn / YEH-rahn

Alternative -se forms ( equally correct, less common in speech)

Person -ar -er / -ir
yo -ase -iese
tú -ases -ieses
él / ella / usted -ase -iese
nosotros -ásemos -iésemos
vosotros (Spain) -aseis -ieseis
ellos / ustedes -asen -iesen
