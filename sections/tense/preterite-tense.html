Preterite (Simple Past)

Preterite Tense

The preterite is used for completed actions in the past (what happened, when, or how many times).
Every form includes pronunciation. Default = LatAm; Spain only if different.

Quick start
Idea Spanish term Example Pronunciation English
Dictionary form infinitive hablar ah-BLAHR = to speak ah-BLAHR to speak
Who did it subject yo yoh, tú too, él ehl… yoh, too, ehl
Ending that shows person + past conjugation hablé ah-BLEH = I spoke ah-BLEH I spoke

Present-tense endings (regular)

Person (Subject Pronoun) -ar -er -ir Pronunciation pattern
yo yoh (I) -o -o -o ends in oh
tú too (you, informal singular) -as -es -es -as = ahs; -es = ehs
él ehl / ella EH-yah / usted oos-TEHD (he / she / you, formal singular) -a -e -e -a = ah; -e = eh
nosotros noh-SOH-trohs / nosotras noh-SOH-trahs (we) -amos -emos -imos AH-mohs / EH-mohs / EE-mohs
vosotros boh-SOH-trohs / vosotras boh-SOH-trahs (you all, Spain) -áis -éis -ís AHEES / EHEES / EES
ellos EH-yohs / ellas EH-yahs / ustedes oos-TEH-dehs (they / you all formal) -an -en -en ahn / ehn

Past-tense Preterite endings (regular)

Person (Subject Pronoun) -ar -er / -ir Pronunciation pattern
yo yoh (I) -é -í -é = EH; -í = EE
tú too (you, informal singular) -aste -iste -aste = AHS-teh; -iste = EES-teh
él ehl / ella EH-yah / usted oos-TEHD (he / she / you, formal singular) -ó -ió -ó = OH; -ió = YOH
nosotros noh-SOH-trohs / nosotras noh-SOH-trahs (we) -amos -imos AH-mohs / EE-mohs
vosotros boh-SOH-trohs / vosotras boh-SOH-trahs (you all, Spain) -asteis -isteis AHS-teys / EES-teys
ellos EH-yohs / ellas EH-yahs / ustedes oos-TEH-dehs (they / you all formal) -aron -ieron AH-rohn / YEH-rohn

Key differences from Present

  • Stress usually falls on the ending (hablé, comí, vivió).
  • -ar and -er/-ir share almost no endings (unlike the present).
  • Many common verbs are irregular in the preterite (ser/ir, estar, tener, hacer, etc.).
