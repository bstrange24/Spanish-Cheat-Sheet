Preterite (Simple Past)

Preterite Tense

The preterite is used for completed actions in the past (what happened, when, or how many times).
Every form includes pronunciation. Default = LatAm; Spain only if different.

Quick start
Idea Spanish term Example Pronunciation English
Dictionary form infinitive hablar = to speak ah-BLAHR to speak
Who did it subject yo, tú, él… yoh, too, ehl
Ending that shows person + past conjugation hablé = I spoke ah-BLEH I spoke

Three verb families (by infinitive ending)

Type Ending Example Pronunciation English

Present-tense endings (regular)

Person (Subject Pronoun) -ar -er -ir Pronunciation pattern
yo (I) -o -o -o ends in oh
tú (you, informal singular) -as -es -es -as = ahs; -es = ehs
él / ella / usted (he / she / you, formal singular) -a -e -e -a = ah; -e = eh
nosotros / nosotras (we) -amos -emos -imos AH-mohs / EH-mohs / EE-mohs
vosotros / vosotras (you all, Spain) -áis -éis -ís AHEES / EHEES / EES
ellos / ellas / ustedes (they / you all formal) -an -en -en ahn / ehn

Past-tense Preterite endings (regular)

Person (Subject Pronoun) -ar -er / -ir Pronunciation pattern
yo (I) -é -í -é = EH; -í = EE
tú (you, informal singular) -aste -iste -aste = AHS-teh; -iste = EES-teh
él / ella / usted (he / she / you, formal singular) -ó -ió -ó = OH; -ió = YOH
nosotros / nosotras (we) -amos -imos AH-mohs / EE-mohs
vosotros / vosotras (you all, Spain) -asteis -isteis AHS-teys / EES-teys
ellos / ellas / ustedes (they / you all formal) -aron -ieron AH-rohn / YEH-rohn

Key differences from Present

  • Stress usually falls on the ending (hablé, comí, vivió).
  • -ar and -er/-ir share almost no endings (unlike the present).
  • Many common verbs are irregular in the preterite (ser/ir, estar, tener, hacer, etc.).

Examples (regular verbs)
Spanish LatAm Spain (if different) English
Hablé español ayer 🔊 ah-BLEH ehs-pah-NYOHL ah-YEHR same I spoke Spanish yesterday.

Nosotros comimos pizza 🔊 noh-SOH-trohs koh-MEE-mohs PEET-sah same We ate pizza.
¿Qué comiste? 🔊 kay koh-MEES-teh same What did you eat?
Viví en Texas dos años 🔊 bee-BEE ehn TEHK-sahs dohs AH-nyohs same I lived in Texas for two years.
¿Dónde viviste? 🔊 DOHN-deh bee-BEES-teh same Where did you live?
Ellos vivieron aquí 🔊 EH-yohs bee-BYEH-rohn ah-KEE same They lived here.
Vosotros hablasteis muy bien 🔊 (Spain) — boh-SOH-trohs ah-BLAHS-teys mwee byehn You all spoke very well.
More useful regular verbs (preterite stem + meaning)

Drop -ar / -er / -ir, then add the preterite endings above. Pronunciations below are for the infinitive and the yo form.
