Negative Imperative

Negative Commands

Negative commands tell someone not to do something.
All forms use the present subjunctive.
Every form includes pronunciation. Default = LatAm; Spain only if different.

Quick start – Negative Imperative endings
Person -ar -er / -ir
tú -es -as
usted -e -a
nosotros -emos -amos
vosotros (Spain) -éis -áis
ustedes -en -an

Key points

  • Always start with no.
  • All persons use the present subjunctive forms.
  • Object and reflexive pronouns go before the verb (unlike affirmative).
Regular verbs: full negative imperative

• hablar — to speak → ah-BLAHR

Person Spanish Pronunciation English
tú no hables noh AH-blehs Don’t speak! (informal)
usted no hable noh AH-bleh Don’t speak! (formal)
nosotros no hablemos noh ah-BLEH-mohs Let’s not speak!
vosotros (Spain) no habléis noh ah-BLEHS Don’t speak! (you all)
ustedes no hablen noh AH-blehn Don’t speak! (you all)
