Negative Imperative

Negative Commands

Negative commands tell someone not to do something.
All forms use the present subjunctive.

Quick start – Negative Imperative endings
Person -ar -er / -ir
tú too -es -as
usted oos-TEHD -e -a
nosotros noh-SOH-trohs -emos -amos
vosotros boh-SOH-trohs (Spain) -éis -áis
ustedes oos-TEH-dehs -en -an

Key points

  • Always start with no.
  • All persons use the present subjunctive forms.
  • Object and reflexive pronouns go before the verb (unlike affirmative).
Regular verbs: full negative imperative

• hablar ah-BLAHR — to speak → ah-BLAHR

Person Spanish Pronunciation English
tú too no hables noh AH-blehs noh AH-blehs Don’t speak! (informal)
usted oos-TEHD no hable noh AH-bleh noh AH-bleh Don’t speak! (formal)
nosotros noh-SOH-trohs no hablemos noh ah-BLEH-mohs noh ah-BLEH-mohs Let’s not speak!
vosotros boh-SOH-trohs (Spain) no habléis noh ah-BLEHS noh ah-BLEHS Don’t speak! (you all)
ustedes oos-TEH-dehs no hablen noh AH-blehn noh AH-blehn Don’t speak! (you all)
